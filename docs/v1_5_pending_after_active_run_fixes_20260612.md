# V1.5 当前运行结束后待落地修复清单

创建时间：2026-06-12

目的：当前 6 通道 CO2/H2O open-flow no-write 队列仍在运行。为避免中途修改 runner/source/config 造成同一轮证据混用不同代码合同，本文件只记录待修复事项，不改变正在运行的流程。

## 运行中不得直接修改的内容

- `src/gas_calibrator/tools/run_v1_5_formal_co2_open_flow_queue.py`
- `src/gas_calibrator/tools/run_v1_5_formal_h2o_open_flow_queue.py`
- 当前运行使用的配置、点表、runner 入口
- 任何会被后续点位子进程重新 import 的 V1.5 源码

原因：当前队列按点启动子进程，若中途改源码，可能出现前半轮旧合同、后半轮新合同，导致证据链不可复核。

## 待修复事项

1. CO2 拟合点角色收敛
   - 正式开放流通标准气点中，`fit` 和 `verification` 只要 QC 合格、非诊断、非拒绝，都应进入候选拟合。
   - 原 `verification` 点被纳入拟合后，候选状态必须标记为需要新的写后独立复验。
   - 导出时应显式使用或默认落实 `fit_all_eligible_samples` 合同，不能静默只用 `fit` 点。

2. 开阀瞬时压力升高处理
   - 开放流通刚开阀时，PACE/COM22 出现短暂高压尖峰应先判为 transient diagnostic。
   - 只有持续超限、无法回落、或达到安全风险阈值时才阻断该点。
   - 报告中保留瞬时压力证据和持续时间，避免误删可用标准气点。

3. 采样窗口必须发生在通气状态下
   - 阀门必须保持打开直到 sample window 完成。
   - `route_open_until_sample_end` 必须作为硬证据进入点位 QC。
   - 任何先关阀再取窗口的数据不得进入正式拟合。

4. 每台分析仪独立判稳
   - ratio、状态寄存器、有效帧、温度/压力诊断都应按设备独立判定。
   - 某一台未稳不应拖死全部设备；合格设备保留 A/B/C/拒绝等级。
   - 拟合阶段按设备 ID 汇总，不按 GA 串口别名做身份。

5. 气路采样条件更明确
   - 气路不能只看时间到达。
   - 需要同时记录并评审：标准气持续开放流通、露点/干燥状态、CO2 ratio 稳定、状态寄存器、有效帧、外部压力参考。
   - 露点不要求每瓶完全相同，但必须能解释当前干燥状态，不把湿气差异误吸收到 CO2 系数。

6. 水路 HGEN 控制优化
   - 水路完整运行期间，湿度发生器不应每个湿度点反复关停/启动。
   - 建议保持 HGEN 工作，只切目标点；温箱等待阶段允许 HGEN 预热/预冷。
   - 压力波动在开放流通水路中默认作为诊断项，不作为硬阻断，除非达到安全或物理不可解释范围。

7. 统一证据状态自动刷新
   - 跑完、拟合、写入、复验、入库、出证后，必须自动重建 `v1_5_run_evidence_status.json` 或等价状态索引。
   - 目标是让审计系统能看到最终闭环，而不是只靠人工知道流程已完成。
