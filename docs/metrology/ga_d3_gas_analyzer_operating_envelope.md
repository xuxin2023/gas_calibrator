# GA-D3 气体分析仪综合工作包络

## 1. 范围

GA-D3 面向气体分析仪本体，把静态浓度性能、环境敏感性、交叉干扰和 GA-D2 动态响应放入同一份可审计工作包络。

它不包含：

- 涡动协方差、协谱修正或通量闭合；
- 校准系数拟合、SENCO 写入或设备回写；
- 真实 COM、真实设备或正式计量验收；
- 对生产数据自动应用动态反卷积。

因此，单独用于稳态气体浓度测量的分析仪仍需要 GA-D3 中的静态、环境和干扰评价；只有在秒级变化或快速过程场景中，才需要把 GA-D2 动态门禁一起纳入使用边界。EC 专属计算不属于本合同。

## 2. 为什么不能只给一个温度、压力和流量范围

只有 `min/max` 数值不能证明整个长方体范围都经过评价。内部缺一个角点时，外层最小值和最大值仍可能看起来完整。

GA-D3 使用严格的笛卡尔积网格：

- 温度：5、25、45 °C；
- 压力：850、1000、1100 hPa；
- 流量：8、12、16 slpm；
- 合计 27 个环境格点；
- 每个格点包含 4 个气体目标、升序/降序、起始/结束会话和 3 次重复。

每个气体共 1296 行静态测量。缺行、重复行或网格外行都会使矩形包络失败，不能通过外层范围掩盖。

## 3. CO2 与 H2O 锚点

两类低端点保持独立物理含义：

- CO2：`co2_zero_gas`，目标 0 ppm；
- H2O：`h2o_dry_gas`，目标 0.2 mmol/mol。

CO2 零气用于检查 CO2 零点。H2O 干气点用于评价水汽通道在可实现低湿条件下的响应和记忆边界。二者不能因数值都处于低端而合并，也不能互相替代。

合同要求每一个锚点目标行都带有正确角色，非锚点行不得伪装成锚点。角色或目标错配会触发硬失败。

## 4. 静态和环境指标

对每个气体分别计算：

- 最大绝对锚点误差；
- 最大量程归一化误差；
- 同条件重复测量的样本标准差；
- 升序与降序均值差形成的回差；
- 起始与结束会话均值差形成的漂移；
- 标称温压流条件下线性回归的最大残差；
- 压力灵敏度，归一到每 100 hPa；
- 温度灵敏度，归一到每 10 °C；
- 流量灵敏度，归一到每 1 slpm；
- 干扰气变化造成的最大输出范围。

所有相对指标均以各气体合同量程归一化。环境格点还会单独保存最大量程误差、最大锚点误差和合格状态，便于定位局部坏角点。

当前数值限值是有界合成夹具的回归规格，不是实际产品规格。正式产品规格必须由目标硬件、气路、参考标准、环境箱能力、重复试验和计量不确定度共同确定。

## 5. 交叉干扰

GA-D3 单独生成受控干扰序列：

- CO2 通道在不同 H2O 水平下评价；
- H2O 通道在不同 CO2 水平下评价。

干扰效应以各干扰水平输出均值的极差除以本通道量程。它与主浓度线性、漂移和环境敏感性分开报告，避免一个指标掩盖另一个物理机制。

## 6. 动态依赖

GA-D3 不重复实现动态谱估计，而是引用 GA-D2 的受控输出：

- 10% 衰减可用带宽；
- 低频等效相位延迟；
- 10% 带宽是否达到 `qualified` 决策等级。

CO2 和 H2O 分别使用自己的动态门限。H2O 的吸附/解吸记忆通常更强，因此不能直接套用 CO2 的响应时间或带宽结论。

动态衰减仍作为系统性动态偏差报告，不混入不确定度掩盖，也不产生自动修正系数。

## 7. 失败语义

以下任一情况都会使综合包络失败：

- 缺失、重复或网格外测量；
- 必需字段缺失、非有限数值、不可用帧或参考质量降级；
- 静态、干扰和动态数据的分析仪身份不唯一或不一致；
- CO2 零气和 H2O 干气角色错配；
- 任一环境格点的误差或锚点误差超限；
- 重复性、回差、漂移、线性或温压流敏感性超限；
- 交叉干扰超限；
- 交叉干扰序列缺点、重复、越界或包含不合格参考；
- GA-D2 动态依赖不完整；
- 10% 带宽不足、相位延迟过大或决策等级不合格。

失败报告保留气体、分析仪、门禁名称和失败格点预览，不输出模糊的单一总分。

## 8. 工件与证据边界

输入工件角色为 `execution_rows`，综合报告和 GA-D2 依赖报告角色为 `diagnostic_analysis`。所有工件固定标记：

- `evidence_source = simulated`
- `not_real_acceptance_evidence = true`
- `acceptance_level = offline_regression`
- `promotion_state = blocked`
- `ec_flux_status = not_in_scope`
- `real_acceptance_status = blocked`
- `coefficient_fit_status = not_applied`
- `coefficient_writeback_status = not_applied`
- `dynamic_correction_status = not_applied`

GA-D3 不修改 V1、不修改 `run_app.py`、不连接真实 COM、不写系数、不刷新 `real_primary_latest`。

## 9. 验证命令

```powershell
$env:PYTHONPATH = "src"
python -m pytest -q tests/v2/test_gas_analyzer_operating_envelope.py
python -m gas_calibrator.v2.scripts.run_simulation_suite --suite regression
python -m gas_calibrator.v2.scripts.run_simulation_suite --suite nightly
python -m gas_calibrator.v2.scripts.run_simulation_suite --suite parity
```

真实分析仪若要形成正式工作包络，仍需独立批准的台架协议、可溯源参考气体和仪器、稳定温压流控制、随机化试验顺序、多轮重复、恢复/记忆评价及正式不确定度预算。
